This key

Shows when one of T3 Code's scheduled tasks runs next, and how its last run went. A failed run stays red until the next run succeeds. Tap opens the task's thread in T3 Code (or T3 Code itself when it has none yet). Hold 0.8 s runs the task now; that changes T3 Code, so it works only while Enable thread actions is on below. Webhook tasks can't be run by hand. Only the task's title, schedule and results are read, never its prompt.
