Dictate

Lets this key press T3 Code's dictation shortcut (composer.dictation, ⇧⌘D by default) in the T3 Code app, and nothing else: no other keys, no text, no other app. It only presses it while T3 Code is the frontmost app. Off: the key does nothing and runs nothing.
Needs two things on this Mac: voice input set up in T3 Code (Settings → Voice), and Stream Deck allowed under System Settings → Privacy & Security → Accessibility (the key says so when it isn't). How this works

This key

Tap or hold, like the shortcut on a keyboard: T3 Code's own Dictation shortcut setting decides what each does. Letter shortcuts assume a QWERTY-style layout; on another layout, bind composer.dictation to a function key in T3 Code.
