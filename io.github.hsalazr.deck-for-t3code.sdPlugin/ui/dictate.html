Dictate

Lets this key press the chord bound to T3 Code's dictation shortcut (composer.dictation, ⇧⌘D by default), looked up in T3 Code on every press, and nothing else: no other keys, no text, no other app. It only presses it while T3 Code is the frontmost app, and sends it to T3 Code itself. Off: the key does nothing and runs nothing.
Needs two things on this Mac: voice input set up in T3 Code (Settings → Voice), and Stream Deck allowed under System Settings → Privacy & Security → Accessibility (the key says so when it isn't). How this works

This key

Tap or hold, like the shortcut on a keyboard: T3 Code's own Dictation shortcut setting decides what each does. As on a keyboard, what has focus in T3 Code matters: with its terminal focused, ⇧⌘D splits the terminal, so click into the composer first or give dictation its own chord (a function key) in T3 Code. Letter shortcuts work on any keyboard layout that has the letter.
