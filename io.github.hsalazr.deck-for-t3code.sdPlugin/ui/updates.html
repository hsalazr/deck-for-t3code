This key

Shows whether T3 Code or one of its provider CLIs (Claude, Codex…) has an update waiting. T3 Code is compared with the newest release on its own channel (stable, or nightly if you run a nightly build); provider CLIs use T3 Code's own update checks, so keep Check for provider updates on in T3 Code's settings. Checked every 30 minutes. Tap to open T3 Code when an update is waiting, or to check again. How this works
