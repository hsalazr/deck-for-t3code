This key

Thread keys fill from top-left to bottom-right, in order, with no gaps. When a thread leaves, the rest slide up. If there are more threads than keys, threads needing you and working threads win. Subagents fold into their main thread.
Tap: open in T3 Code (clears its highlight). Hold, and release once the key says so: the Thread Actions page for that thread, with your quick messages, Compact, Snooze, Settle and Stop. Stop, Settle, Compact and messages only fire when held for 0.8 s.

Quick messages

Each line becomes a key on the Thread Actions page, in order (up to 21 on Stream Deck XL, 7 on Stream Deck, 2 on Neo, none on Mini). Hold a message key to send it, as if typed in T3. Write Label | full text to show a short label on the key and send the full text.
